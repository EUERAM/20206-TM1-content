# 01 — HTML structure

This example demonstrates guide topic **1: Creating an HTML file and its tag structure**. It contains one heading and one paragraph inside the basic HTML document skeleton.

The comments in `index.html` identify the document, head, and body. The linked CSS has comments explaining its simple page styles.
