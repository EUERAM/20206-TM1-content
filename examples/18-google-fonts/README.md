# 18 — Google Fonts

This example demonstrates guide topic **18: Linking a Google Font**. It preconnects to Google Fonts, loads the Poppins family, and applies it to the page with a sans-serif fallback.

An internet connection is needed to download Poppins; if it cannot load, the browser uses its fallback font.
