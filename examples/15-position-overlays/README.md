# 15 — Absolute positioning with overlays

This example demonstrates guide topic **15: Position — relative vs absolute (overlays)**. Hover over or focus the card to reveal an overlay. The card is `position: relative`, so its absolutely positioned overlay is placed within the card.

## Folder structure

```text
15-position-overlays/
├── index.html
├── README.md
└── css/
    └── style.css
```

Open `index.html` in a browser, then hover over the card or use the keyboard to focus it.
