# 12 — Flex layout

This example demonstrates guide topic **12: Flex layout**. Three boxes are arranged in a row with equal space between them using `display: flex` and `justify-content`.

The page focuses on Flexbox only: it does not add a grid or responsive breakpoint. Comments in the HTML and CSS identify the flex container and its layout rules.
