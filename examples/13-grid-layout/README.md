# 13 — Grid layout

This example demonstrates guide topic **13: Grid layout**. Six boxes are placed in three equal-width columns using `display: grid`, `grid-template-columns`, and `gap`.

The page focuses on a basic grid without adding Flexbox or media queries. Comments in the HTML and CSS identify the grid container and its column rules.
