# 20 — Animations

This example demonstrates guide topic **20: Animations (`@keyframes`)**. A coloured dot bounces automatically using named keyframes and the CSS `animation` property.

The reduced-motion media query limits the animation for visitors who request less motion in their system settings.

The example focuses on the animation itself: it does not use a transition or media query.
