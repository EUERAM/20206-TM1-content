# 17 — Icons with Font Awesome

This example demonstrates guide topic **17: Including Font Awesome**. It loads the Font Awesome stylesheet from its CDN and uses icon classes in the page.

An internet connection is needed to load the icons. The icon-only links have accessible labels for screen readers.
