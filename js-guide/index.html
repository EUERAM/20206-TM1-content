JavaScript fundamentals

1.1 What is JavaScript, and why use it?

JavaScript (JS) is a programming language that runs in the browser. HTML describes a page's content, CSS controls its presentation, and JavaScript responds to actions and changes what the page does.

For designers, JS can make a menu open, validate a form, update a counter, play a sound, or react to scrolling. Start with a clear user need: interactivity should make a task clearer or easier, not add motion without purpose.

JavaScript fundamentals

1.2 How to include JavaScript in HTML

Put code in a separate .js file and load it with a <script> element. The defer attribute lets the browser finish reading the HTML before running the script, so the elements are ready to select. 

<!-- In index.html, near the end of <head> -->
<script src="js/main.js" defer></script>
// In js/main.js
console.log("JavaScript is connected");

Check the browser's developer tools Console. If the message appears, the file loaded. Check spelling and the relative file path if it does not.

Avoid inline event attributes such as onclick="...". Keeping behavior in a JS file makes it easier to read, maintain, and debug.

JavaScript fundamentals

1.3 Debugging JavaScript

Debugging means finding and fixing the cause of unexpected behavior. Read the first error in the Console: it often names the problem and points to the file and line where it occurred.

  • Use console.log(value) to inspect a value while the program runs.
  • Check the Console for syntax errors and the Network panel for missing files or failed requests.
  • Add a breakpoint in the Sources panel to pause execution and inspect variables one step at a time.
  • Test one small change at a time, then remove temporary logs that are no longer useful. 
const button = document.querySelector("#save-button");
console.log("Save button found:", button);

JavaScript fundamentals

1.4 Core components

Programs combine values, decisions, repetition, and reusable actions. These building blocks are enough to begin adding useful interface behavior.

Variables

Use const by default for a binding that will not be reassigned, and let when it will. Avoid var in new code. 

const courseName = "Digital Interaction";
let completedLessons = 0;
completedLessons = completedLessons + 1;

Conditionals

Use if and else to choose what happens based on a condition. 

if (completedLessons > 0) {
console.log("Keep going!");
} else {
console.log("Start with lesson one.");
}

Loops

A loop repeats an action. Use for...of to process each item in a list. 

const topics = ["HTML", "CSS", "JavaScript"];

for (let i=0; i < topics.length; i++ ) {
  console.log(topics[i]);
}

Functions

A function packages a task that can be called when needed. Parameters let it work with different values. 

function greet(name) {
return `Hello, ${name}!`;
}

console.log(greet("Alex"));

JavaScript fundamentals

1.5 Types of variables

A variable stores a value, and each value has a type. JavaScript has seven primitive types and objects. Choose const or let to declare a variable; these keywords do not determine the value's type.

Primitive types

  • string: text, such as "Hello"
  • number: integers and decimals, such as 42 or 3.14
  • boolean: true or false
  • undefined: a declared variable without an assigned value
  • null: an intentionally empty value

Objects and collections

An object stores related information as named key-value pairs. An array stores an ordered list of values, which you access by their position. Use an object to describe one course and an array to list its topics. 

const course = {
  title: "UX Design",
  lessonCount: 8
};

const topics = ["Research", "Wireframes", "Prototype"];

console.log(course.title); // "UX Design"
console.log(topics[0]);    // "Research"

Use typeof value to inspect most types. Two historical JavaScript quirks: typeof null returns "object", and arrays also return "object". Use Array.isArray(value) when you need to identify an array.

JavaScript fundamentals

1.6 Conditionals

Conditionals choose which code runs. Compare values with strict equality (=== and !==) and combine conditions with && (and), || (or), and ! (not).

If, else if, and else

Use these when a decision has one or more possible conditions. 

const progress = 72;

if (progress === 100) {
console.log("Course complete");
} else if (progress > 0) {
console.log("Keep learning");
} else {
console.log("Start the course");
}

Switch

Use switch to compare one value with several specific cases. Include break to prevent execution from falling through to the next case. 

const status = "published";

switch (status) {
case "draft":
  console.log("Not visible yet");
  break;
case "published":
  console.log("Visible to learners");
  break;
default:
  console.log("Unknown status");
}

Ternary operator

Use condition ? valueIfTrue : valueIfFalse for a short choice between two expressions, not for long blocks. 

const buttonLabel = isPublished ? "Open lesson" : "Coming soon";

Values such as 0, "", false, null, and undefined are falsy. Most other values are truthy. Keep conditions explicit so the intended behavior is easy to understand.

JavaScript fundamentals

1.7 Loops

Loops repeat work. Choose the form that makes the stopping condition and the values being processed clear.

Counted for loop

Use when you need an index or a known number of repetitions.

const lessons = ["Research", "Wireframes", "Prototype"];

for (let index = 0; index < lessons.length; index++) {
console.log(index + 1, lessons[index]);
}

while loop

Checks its condition before each repetition, so it may run zero times. 

let attempts = 0;

while (attempts < 3) {
console.log("Try", attempts + 1);
attempts++;
}

do...while loop

Runs its body once before checking the condition.

let answer;

do {
answer = prompt("Type 'try again' to repeat");
} while (answer === "try again");

for...of loop

Reads each value from an iterable, such as an array or string. 

for (const lesson of lessons) {
console.log(lesson);
}

for...in loop

Iterates over an object's enumerable property names. Check Object.hasOwn() to avoid including properties inherited from its prototype. For arrays, use for...of instead. 

const learner = { name: "Alex", course: "UX Design" };

for (const key in learner) {
  if (Object.hasOwn(learner, key)) {
    console.log(key, learner[key]);
  }
}

Array forEach()

Calls a function for each array item when you do not need to stop the iteration early or return a new array. 

lessons.forEach((lesson, index) => {
console.log(index + 1, lesson);
});

break exits a loop and continue skips to its next iteration. Always make sure a while loop can eventually reach its stopping condition.

JavaScript fundamentals

1.8 Functions

Functions package reusable behavior. They can accept parameters, return a value, and be passed to other functions.

With and without variables (parameters)

A function can work without any input, or receive values through parameters: variables listed in the parentheses. The values you pass when calling it are called arguments. 

// Without parameters: always does the same thing
function sayHello() {
  console.log("Hello!");
}

sayHello(); // "Hello!"

// With parameters: the result depends on the values you pass
function sayHelloTo(name, course) {
  console.log(`Hello, ${name}! Welcome to ${course}.`);
}

sayHelloTo("Alex", "UX Design"); // "Hello, Alex! Welcome to UX Design."
sayHelloTo("Mina", "JavaScript"); // "Hello, Mina! Welcome to JavaScript."

Returning and not returning a value

A function that uses return sends a value back to the place where it was called, so you can store it in a variable or use it in another expression. A function without return only performs an action, such as logging or changing the page, and gives back undefined. 

// Does not return: performs an action
function showTotal(price, quantity) {
  console.log(price * quantity);
}

const result1 = showTotal(5, 3); // logs 15
console.log(result1);            // undefined

// Returns: gives a value back to use later
function calculateTotal(price, quantity) {
  return price * quantity;
}

const result2 = calculateTotal(5, 3);
console.log(result2);      // 15
console.log(result2 + 10); // 25

return also ends the function immediately: any code after it is not executed.

Function declaration

A named function declaration can be called before its definition. 

function greet(name) {
return `Hello, ${name}!`;
}

console.log(greet("Alex"));

Function expression

A function expression is stored in a variable. It can be anonymous or named; the variable binding shown here is const. 

const calculateProgress = function (completed, total) {
return (completed / total) * 100;
};

const formatProgress = function formatProgress(value) {
return `${Math.round(value)}%`;
};

Functions can also use default parameters, rest parameters (...values), and return values. Prefer clear names and small functions that do one job.

JavaScript fundamentals

1.9 Time control: setTimeout and setInterval

JavaScript can run a function later or repeatedly using timers. The time is given in milliseconds (1000 ms = 1 second). Timers do not block the page: the rest of the code keeps running while the browser waits.

setTimeout(): run once after a delay

const timeoutId = setTimeout(() => {
  console.log("Two seconds have passed");
}, 2000);

// Cancel it before it runs
clearTimeout(timeoutId);

setInterval(): run repeatedly

It calls the function every time the interval passes, until you stop it with clearInterval(). 

let seconds = 0;

const intervalId = setInterval(() => {
  seconds++;
  console.log(`Seconds: ${seconds}`);

  if (seconds === 5) {
    clearInterval(intervalId);
  }
}, 1000);

Example: a countdown in the page

const display = document.querySelector("#countdown");
let remaining = 10;

const timer = setInterval(() => {
  remaining--;
  display.textContent = remaining;

  if (remaining === 0) {
    clearInterval(timer);
    display.textContent = "Time is up!";
  }
}, 1000);

setTimeout

Runs the function once. Use it for delays, such as hiding a message after a few seconds.

setInterval

Runs the function repeatedly. Use it for clocks, counters, or slideshows.

Always keep the returned id and clear timers you no longer need. Timing is approximate: the delay is a minimum, not a guarantee. For smooth animation, prefer requestAnimationFrame() or CSS animations over short intervals.

DOM & interface interactivity

2.1 What is a DOM?

The Document Object Model (DOM) is the browser's live, tree-shaped representation of an HTML document. JavaScript can find DOM elements and update their text, attributes, classes, or children. A DOM change updates the rendered page.

document the page
body page content
button interactive control
p text content

DOM & interface interactivity

2.2 How to select elements

CSS selectors work in JavaScript too. Use querySelector() to get the first match, or querySelectorAll() to get all matches. 

const title = document.querySelector("h1");
const menuButton = document.querySelector("#menu-button");
const cards = document.querySelectorAll(".card");

if (title) {
title.textContent = "Welcome to the project";
}

Select every match with querySelectorAll()

querySelectorAll() returns a list of all matching elements. Use forEach() to run an action for each one, such as reading the text from every card in the main content. 

const cards = document.querySelectorAll("main .info-card");

cards.forEach((card, index) => {
console.log(`Card ${index + 1}:`, card.textContent.trim());
});

A selector may not match anything, so querySelector() can return null. Check that the element exists before trying to change it. Prefer textContent for plain text; inserting untrusted content with innerHTML can create security problems.

Events & user input

3.1 What is an event?

An event is a signal that something happened: a person clicked, pressed a key, submitted a form, or scrolled, for example. Register an event listener to run a function in response. 

element.addEventListener("event-name", (event) => {
// Respond to the event here.
});

The event object contains details about the interaction, such as which element received it or which key was pressed.

Common types of events

Mouse and pointer

  • click, dblclick
  • mouseover, mouseout
  • pointerdown, pointerup, pointermove

Keyboard

  • keydown
  • keyup

Forms

  • submit
  • input (value changes as you type)
  • change (value committed)
  • focus, blur

Window and document

  • load, DOMContentLoaded
  • scroll
  • resize

Touch

  • touchstart, touchmove, touchend

Media

  • play, pause, ended
  • timeupdate

Events & user input

3.2 Click and form events

Use click for a button action. For a form, listen to submit so the same behavior works for a button click and for submitting with the keyboard. 

const button = document.querySelector("#show-message");
const message = document.querySelector("#message");

button?.addEventListener("click", () => {
if (message) message.textContent = "Thanks for clicking!";
});
const form = document.querySelector("#signup-form");

form?.addEventListener("submit", (event) => {
event.preventDefault();
console.log("Form submitted");
});

preventDefault() stops the browser's default form navigation so the page can handle the submission. Validate input and give the person clear feedback.

Events & user input

3.3 Scroll events

The scroll event can respond to page movement, but it may fire many times per second. Keep the handler small; use requestAnimationFrame() for frequent visual updates, or consider IntersectionObserver for detecting when content enters the viewport. 

window.addEventListener("scroll", () => {
const hasScrolled = window.scrollY > 200;
document.body.classList.toggle("has-scrolled", hasScrolled);
}, { passive: true });

Events & user input

3.4 Mouse and pointer events

Events such as pointerenter, pointerleave, and pointerdown can react to mouse, pen, and touch input. Prefer pointer events when the same interaction should support different pointer devices. Do not make essential information available only on hover.

The mousemove event fires whenever the mouse moves. Its event object provides the pointer position: clientX and clientY are measured from the top-left corner of the viewport. This example reads both values and writes them into a div in the page. 

<div id="coordinates">X: 0, Y: 0</div>
const coordinates = document.querySelector("#coordinates");

document.addEventListener("mousemove", (event) => {
  const x = event.clientX;
  const y = event.clientY;

  if (coordinates) {
    coordinates.textContent = `X: ${x}, Y: ${y}`;
  }
});

mousemove only reacts to a mouse. Use pointermove instead if the same code should also work with touch and pen input.

Events & user input

3.5 Keyboard events

Keyboard interactions fire up to three events, in this order. Prefer native buttons, links, and form controls: they already provide expected keyboard behavior.

keydown

Fires when a key is pressed down, and repeats while the key is held. Works for every key, including Escape, arrows, Shift, and Ctrl. Use it for shortcuts and controls.

keyup

Fires once when the key is released. Use it to detect the end of an action, or to read a field's value after the last character has been typed.

keypress

Fired only for keys that produce a character, and not for Escape, arrows, or Shift. It is deprecated: use keydown or the input event instead. 

const log = document.querySelector("#key-log");

document.addEventListener("keydown", (event) => {
log.textContent = `keydown: ${event.key}`;
});

document.addEventListener("keyup", (event) => {
log.textContent = `keyup: ${event.key}`;
});

Press and hold a key: keydown repeats while it is held, and keyup runs once when you let go. Use keydown when a keyboard interaction is meaningful, such as Escape closing a dialog. 

document.addEventListener("keydown", (event) => {
if (event.key === "Escape") {
  closeDialog();
}
});

Avoid capturing keys globally when the user is typing in a field. Check event.key and keep shortcuts discoverable and accessible.

State & CSS

4.1 Add, remove, and toggle classes

The “add/remove class” technique keeps responsibilities clear: JavaScript changes the interface state, while CSS describes how that state looks. Use classList.add(), remove(), toggle(), and contains(). 

const menu = document.querySelector("#menu");
const menuButton = document.querySelector("#menu-button");

menuButton?.addEventListener("click", () => {
const isOpen = menu?.classList.toggle("is-open");
menuButton?.setAttribute("aria-expanded", String(Boolean(isOpen)));
});
/* In CSS */
.menu.is-open {
display: block;
}

Keep state and accessibility in sync. For an expandable menu, update aria-expanded as well as the visual class. Use a real button for the control.

State & CSS

4.2 Change styles

Prefer classes for reusable or multi-property visual states. For a single value that must be calculated at runtime—such as an opacity—set it directly with the element's style property. CSS properties become camelCase in JavaScript (background-color becomes backgroundColor). 

const box = document.querySelector(".box");

box.style.opacity = 0.5;
box.style.backgroundColor = "tomato";
box.style.transform = "translateX(20px)";

For a value that several rules in your CSS should share, set a CSS custom property with setProperty() instead. 

box.style.setProperty("--progress", "65%");
/* In CSS */
.progress-bar {
width: var(--progress, 0%);
}

Avoid scattering one-off inline style changes throughout the code. Keeping presentation in CSS makes states consistent and easier to maintain.

HTML5 media

5.1 Audio and video elements

HTML5 adds <audio> and <video> elements that play media without plugins. The browser exposes them through the DOM, so JavaScript can read their properties and call their methods. Keep visible controls available unless you provide an equally accessible alternative.

Properties and methods

  • currentTime: the current playback position in seconds. Read it to show progress, or set it to jump to another point.
  • duration: the total length in seconds (read only). It is NaN until the metadata has loaded.
  • paused: true when the media is not playing (read only). Use it to decide whether to call play() or pause().
  • volume: the sound level, from 0 (silent) to 1 (full).
  • muted: true silences the media without changing volume.
  • playbackRate: the playback speed; 1 is normal, 2 is twice as fast, 0.5 is half speed.
  • play(): starts or resumes playback. It returns a Promise that can be rejected by browser policies.
  • pause(): pauses playback and keeps the current position.
  • load(): resets the element and reloads its source, for example after changing src. 
const video = document.querySelector("#demo-video");

video.volume = 0.5;        // 50% volume
video.playbackRate = 1.5;  // 1.5x speed
video.currentTime = 10;    // jump to second 10
video.loop = true;         // same as the loop attribute

Always provide captions with <track> for spoken content, and avoid autoplay with sound.

HTML5 media

5.2 Play and pause

Select a <video> or <audio> element and call its play() and pause() methods from your own buttons.

play() returns a Promise and may be rejected by browser playback policies. Handle that possibility and update the interface based on the media's actual state. 

const video = document.querySelector("#demo-video");
const playButton = document.querySelector("#play-video");
const pauseButton = document.querySelector("#pause-video");

playButton?.addEventListener("click", async () => {
if (video instanceof HTMLVideoElement) {
  try {
    await video.play();
  } catch (error) {
    console.error("Video could not start:", error);
  }
}
});

pauseButton?.addEventListener("click", () => {
if (video instanceof HTMLVideoElement) video.pause();
});

Useful media properties include paused, currentTime, duration, and ended. Listen to events such as play, pause, and timeupdate to keep a custom interface in sync.

HTML5 media

5.3 Mute and unmute

The boolean muted property controls whether a media element's audio is audible. A button can toggle this property and update its accessible label. 

const media = document.querySelector("#demo-video");
const muteButton = document.querySelector("#mute-video");

muteButton?.addEventListener("click", () => {
if (!(media instanceof HTMLMediaElement)) return;

media.muted = !media.muted;
muteButton.setAttribute(
  "aria-pressed",
  String(media.muted)
);
muteButton.textContent = media.muted ? "Unmute" : "Mute";
});

Browsers usually block autoplay with sound. Let people choose when to start media and provide clear controls for playback and volume.

HTML5 media

5.4 Media events

Audio and video elements fire events as their state changes. Listen to them to keep your interface in sync with the media, instead of guessing what it is doing.

Loading

  • loadedmetadata: duration and size are known
  • canplay: enough data to start playing
  • waiting: paused to buffer more data
  • error: the media failed to load

Playback

  • play: playback started or resumed
  • pause: playback was paused
  • ended: playback reached the end
  • timeupdate: currentTime changed

Controls

  • volumechange: volume or muted changed
  • seeking, seeked: the user is jumping to another time
  • ratechange: playback speed changed
const video = document.querySelector("#demo-video");
const status = document.querySelector("#video-status");
const progress = document.querySelector("#video-progress");

video?.addEventListener("loadedmetadata", () => {
  status.textContent = `Duration: ${Math.round(video.duration)} s`;
});

video?.addEventListener("play", () => {
  status.textContent = "Playing";
});

video?.addEventListener("pause", () => {
  status.textContent = "Paused";
});

video?.addEventListener("timeupdate", () => {
  progress.value = (video.currentTime / video.duration) * 100;
});

video?.addEventListener("ended", () => {
  status.textContent = "Finished";
});

timeupdate fires several times per second, so keep its handler small. Wait for loadedmetadata before reading duration: until then it is NaN.

Animations

6.1 Play animations

The Web Animations API lets JavaScript play a sequence of visual keyframes. Use it for feedback or to explain a transition, and keep the effect short and purposeful. 

const notice = document.querySelector(".notice");

notice?.animate(
[
  { opacity: 0, transform: "translateY(8px)" },
  { opacity: 1, transform: "translateY(0)" }
],
{
  duration: 220,
  easing: "ease-out",
  fill: "both"
}
);

Element.animate() returns an Animation object. You can call pause(), play(), or cancel() on it when the interaction needs to control the animation.

AI prompting for code

7.1 How to prompt

Treat generated code as a draft, not a source of truth. Give the assistant context, describe one specific behavior, state constraints, and ask for an explanation and tests.

  1. Provide context: say what the page does and name the HTML elements or files involved.
  2. Describe the outcome: specify what the person does and what should happen next.
  3. Set constraints: request plain JavaScript, accessible controls, no inline handlers, and no unnecessary dependencies if those fit the project.
  4. Ask for explanation: request a short walkthrough of selectors, events, state, and edge cases.
  5. Verify: run the code, inspect errors, test keyboard and mobile behavior, and ask for help fixing a specific failure if one occurs. 
I am learning JavaScript. My page has a button with
id="menu-button" and a navigation element with id="site-menu".

Write a small, beginner-friendly script that toggles the menu when the
button is clicked. Use addEventListener and classList, update aria-expanded,
and explain each step. Do not use a framework or inline HTML handlers.
Include any CSS class the behavior needs and mention how I can test it
with a keyboard.

Never paste private data, credentials, or unpublished user information into an AI tool. Review generated code for correctness, accessibility, security, and fit with the existing project before using it.
